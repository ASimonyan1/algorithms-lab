# Algorithms Lab

**C++17 · СиАОД · Тесты · Разбор сложности**

[![C++ CI](https://github.com/ASimonyan1/algorithms-lab/actions/workflows/cpp.yml/badge.svg)](https://github.com/ASimonyan1/algorithms-lab/actions/workflows/cpp.yml)

Учебная лаборатория алгоритмов и структур данных. Здесь важны не только ответы, но и инварианты, граничные случаи и воспроизводимые проверки. Подготовлено с помощью AI-инструментов; репозиторий предназначен для изучения и самостоятельного развития.

## Содержание

| Алгоритм / структура | Время | Дополнительная память |
|---|---|---|
| Бинарный поиск нижней границы | O(log n) | O(1) |
| Сортировка слиянием | O(n log n) | O(n) |
| Two Sum | O(n) в среднем, O(n²) в худшем случае | O(n) |
| Проверка скобок | O(n) | O(n) |
| Уникальная подстрока, скользящее окно | O(n) | O(1), алфавит 256 байт |
| Максимальная сумма подмассива | O(n) | O(1) |
| Слияние интервалов | O(n log n) | O(n) |
| BFS | O(V + E) | O(V) |
| Итеративный DFS | O(V + E) | O(V + E) |
| Топологическая сортировка | O(V + E) | O(V) |
| Длина строго возрастающей подпоследовательности | O(n log n) | O(n) |
| Минимум монет | O(amount × число номиналов) | O(amount) |

## Запуск за три команды

Нужны CMake 3.16+ и компилятор C++17 (GCC, Clang или MSVC).

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build --config Debug
ctest --test-dir build -C Debug --output-on-failure
```

Демонстрация: `./build/demo` (Windows/MSVC: `build/Debug/demo.exe`).

## Проверки

- Граничные случаи: пустые входы, дубликаты, отрицательные числа, недостижимые вершины, циклы, неверные параметры.
- 1 000 случайных массивов: сортировка и поиск сравниваются со STL, Two Sum и сумма подмассива — с полным перебором, LIS — с O(n²) решением.
- 5 000 смешанных операций: очередь сравнивается с `std::deque`, хеш-таблица — с `std::unordered_map`.
- Все ключи тестовой хеш-таблицы принудительно попадают в одну корзину — проверка коллизий и перераспределения.
- Проверки работают и с `NDEBUG`: тесты не полагаются на отключаемый `assert`.
- CI: Linux/GCC, Windows/MSVC, отдельная Linux-сборка с AddressSanitizer и UBSan.

## Читать код

[`algorithms.hpp`](include/algolab/algorithms.hpp) · [`structures.hpp`](include/algolab/structures.hpp) · [`тесты`](tests/test_algolab.cpp) · [`разборы`](docs/NOTES.md)

Контракты намеренно явные: бинарный поиск принимает отсортированный массив; интервалы замкнутые; уникальная подстрока работает с байтами, не с Unicode-символами; отрицательная сумма и нулевые номиналы в задаче о монетах запрещены. Максимальная сумма пустого массива — `nullopt`.

Это учебные реализации, а не замена STL. Память зависит от размера входа; огромные входы могут привести к `std::bad_alloc`. Хеш-таблица копирует возвращаемые значения и не предоставляет итераторы.
